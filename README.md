# danihp6.github.io

GitHub Pages **user site** for `danihp6`, served at the domain root
`https://danihp6.github.io/`.

Its main job is hosting [`app-ads.txt`](./app-ads.txt) at the root of the developer
domain, which is where AdMob looks. The file lists the publisher
`pub-8140926326613612` and therefore covers every Dustfall / Calcorie app under this
account.
